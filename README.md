# Word and Picture Match Game

An interactive educational game designed for children to learn words through matching pictures and words. The game features drag-and-drop functionality, audio pronunciation, and visual feedback.

## Features

- **Interactive Flashcards**: Drag words to match with corresponding pictures
- **Audio Support**: Click on words to hear their pronunciation
- **Progress Tracking**: Visual progression bar showing completed stages
- **Customizable Game Length**: Choose how many words to match (4-16 cards)
- **Achievement System**: Earn emojis for completing stages
- **Child-Friendly Design**: Colorful interface with engaging animations
- **Responsive Layout**: Works on different screen sizes

## Game Modes

1. **Quick Game**: Match 4 cards
2. **Medium Game**: Match 8 or 12 cards
3. **Full Game**: Match all 16 cards

## How to Play

1. Use the slider to choose how many cards you want to match
2. Click "Play!" to start the game
3. Drag word cards to match them with the correct pictures
4. Click on words to hear their pronunciation
5. Complete all matches to earn emojis and progress to the next stage
6. Win the game by matching all selected cards

## Words Included

- Basic objects: apple, book, ball, house
- Animals: cat, dog, fish, bird
- Nature: tree, sun, moon, star, flower, cloud, rainbow
- And more!

## Technical Requirements

- Modern web browser with JavaScript enabled
- Audio support for word pronunciation
- Touch screen or mouse for drag-and-drop functionality

## Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. No additional installation required

## File Structure

- `index.html` - Main game interface
- `styles.css` - Game styling and animations
- `script.js` - Game logic and functionality
- `images/` - Directory containing word images
- `audio/` - Directory containing word pronunciations
