# Interactive Flashcards

An interactive flashcard application designed for young learners of English. This application includes several engaging features to make learning fun and effective.

## Features

- **Audio Pronunciation:** Click on any flashcard to hear the word pronounced using the Web Speech API
- **Visual Representation:** Each flashcard displays an image representing the word
- **Interactive Animations:** Some flashcards include animations to enhance engagement
- **Matching Game:** A memory-style game where you match words with their corresponding images

## Setup

1. Clone this repository
2. Create an `images` directory in the root folder
3. Add the following images to the `images` directory:
   - apple.png
   - cat.png
   - dog.png
   - book.png

## Usage

1. Open `index.html` in a modern web browser
2. Click on any flashcard to hear the word pronounced
3. Play the matching game by clicking on cards to find pairs
4. Drag and drop flashcards to match them with their corresponding images

## Technical Requirements

- Modern web browser with Web Speech API support
- JavaScript enabled
- Images in PNG format

## Browser Compatibility

This application works best in the following browsers:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari
